Detailed Description

Owner for the common single-part case: keeps the one part descriptor inline so callers can wrap a contiguous payload as segmented input without managing a separate descriptor array.

Must outlive any cursor made from view() (the cursor copies the segments value, but that value points at THIS object's descriptor).
