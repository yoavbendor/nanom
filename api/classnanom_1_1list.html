Detailed Description

template<class E>
class nanom::list< E >

A lazily decoded list: the validated element bytes, the element count, and the element wire type.

Iteration decodes each element in place; nothing is allocated. The bytes are a view into the input buffer (same lifetime contract as nm::bytes).
