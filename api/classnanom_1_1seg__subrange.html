Detailed Description

A subrange cannot alias the parent's part array (its first/last descriptors are trimmed), so it carries its own inline descriptor array — allocation-free, capped at seg_max_parts intersecting parts (subrange() returns nullopt past the cap; gather into owned storage as the fallback).

~1 KiB by value at the default cap: fine as a local, don't store thousands.
