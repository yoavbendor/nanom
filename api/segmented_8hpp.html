◆ NANOM_SEG_MAX_PARTS

#define NANOM_SEG_MAX_PARTS   64

Upper bound on the number of parts a seg_subrange can carry inline (subrange() returns nullopt past it — no allocation, ever).

64 covers IP fragmentation's worst case with headroom: a 64 KiB datagram over IPv6's 1280-byte minimum MTU is ~52 fragments. Override with -DNANOM_SEG_MAX_PARTS.
