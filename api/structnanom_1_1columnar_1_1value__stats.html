Detailed Description

template<class T>
struct nanom::columnar::value_stats< T >

min / max / null count of the non-null values (validity bit set; null validity = all valid).

Integers compare as T (pass an unsigned T for unsigned logical types). Floating point follows the Parquet spec: NaN is ignored (no min / max when every value is NaN), a minimum of +0 is reported as -0 and a maximum of -0 as +0.
