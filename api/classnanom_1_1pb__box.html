Detailed Description

template<class M>
class nanom::pb_box< M >

An optional message held on the heap, for recursive protobuf models (a message that contains one of its own type: nm::field<1, nm::pb_box<Node>, nm::presence::defaulted> child;, which a std::optional<Node> member cannot express).

Absent = empty. Copies are deep.
