Decode one value's codes without bounds checks on dst, advancing it past the decoded bytes: the caller guarantees max_decoded_size(in.size()) writable bytes there (symbols are copied as whole 8-byte words).

Codes are still checked: on a bad one it returns false, leaves dst where it was and, given error, says why. The form for decoding many values into one buffer.
