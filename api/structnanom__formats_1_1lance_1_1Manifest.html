Detailed Description

A dataset version (_versions/{version}.manifest).

Fields 4 (version_aux_data), 6 (index_section) and 21 (transaction_section) are positions inside the manifest file they were read from: a writer drops or recomputes them, never copies them into another file. What is not declared (base paths, branch, ...) is kept in unknown.
