Detailed Description

Non-owning: both the part-descriptor array AND the bytes the parts point at are caller-owned and must outlive the segments object (same lifetime contract as input over a span).

Under NANOM_GENERATION one optional {arena, gen} pair attests ALL parts (the motivating consumer's fragments all point into one capture buffer); multi-arena segments are a v1 non-goal.
