Detailed Description

template<class T>
requires (std::is_trivially_copyable_v<T>)
class nanom::columnar::fixed_dictionary< T >

Dictionary of fixed-width values, compared by their bytes (floats by bit pattern: -0.0 and +0.0 are distinct entries, as are NaN payloads, so decoding reproduces every value exactly).
