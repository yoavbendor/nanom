Detailed Description

template<class M>
class nanom::pb_lazy< M >

A nested message kept as its wire bytes and decoded on demand: the protobuf counterpart of the Thrift codec's lazy<M>.

Reading a pb_lazy<M> member checks only that its length fits and records where the bytes are (no allocation, no recursion), which makes it the cheap way to hold a recursive tree (Lance's encodings) or a large message that is often skipped. decode_into() / decode() run the full, checked decoder on those bytes. For writing, pb_lazy<M>::of(m) points at the caller's message (zero-copy; m must outlive the encode), and bytes read from a file are written back verbatim.

Like any view, a decoded pb_lazy points into the input, which must outlive it. A decode_into() starts its own nesting count: a consumer walking a recursive model of lazies bounds its depth. Protobuf merges a message field that occurs twice; a pb_lazy field cannot merge bytes, so a second occurrence of one is refused (writers emit a message field once).
