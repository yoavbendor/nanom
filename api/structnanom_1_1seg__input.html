Detailed Description

Mirrors input's member API (size/empty/offset/operator[]/safe_at/advance/checked_advance) so cursor-generic helper code can be written against either.

Hot fields are raw pointers into the CURRENT part, so within-segment reads are a pointer compare + deref, exactly like input. The segments descriptor travels BY VALUE inside the cursor, so only the part-descriptor ARRAY (and the bytes) must outlive it – from(owner.view()) with a temporary segments is safe. Invariant: cur == nullptr <=> the cursor is exhausted (empty parts are always skipped over).

inlineconstexpr

THE key primitive: an N-byte read window at the cursor.

Fast path (window inside the current part): w points at segment memory, no copy. Slow path (straddles >= 1 boundary): gathers the N bytes into w's inline stack buffer. Returns false when fewer than N bytes remain.
