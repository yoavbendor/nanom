Detailed Description

Which of n level entries hold a value slot, and which slots are non-null: an entry is a slot when def >= slot_level (its innermost enclosing list has an element there; 0 = every entry), and the slot is non-null when def == max_def.

Sets the validity bits of the slots in bm (zeroed, >= n bits) and returns {slots, non-null}.
