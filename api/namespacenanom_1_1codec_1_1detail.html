LZ77 back-reference copy of len bytes from offset back, allowed to write up to 15 bytes past dst + len (callers guarantee room = writable bytes from dst, and fall back to copy_match when room < len + 16).

Every byte read is either before dst or already written by this copy, so the overshoot never feeds garbage into the result, and the bytes past len are overwritten later.

◆ snappy_table()

consteval std::array< std::uint16_t, 256 > nanom::codec::detail::snappy_table ( )

Snappy tag table, built at compile time: for every tag byte, the element length (bits 0-7), the copy offset's high bits (bits 8-10, copy-1 only) and the count of extra bytes (bits 11-13).

Literals with a length suffix (len > 60) are marked with length 0 and handled out of line.
